# dmm-fanza-affiliate

DMMアフィリエイト(FANZA/成人向けジャンル)の副業プロジェクト。

前のパソコンで途中まで作業していたが、環境移行時に記録が消えたため、
今回からこのリポジトリ内で進捗をgit管理する。

> **注意**: このフォルダは `pinterest-saas-affiliate`(Teamwork/Paymo × Pinterest)とは
> 完全に別プロジェクト。商材・媒体・規約が異なるため混在させない。

## ジャンル

- **対象**: FANZA(成人向け動画・電子コミック等)
- 通常のDMM一般ジャンル(DMM英会話・DMM.com物販・ゲーム等)より、年齢要件・掲載媒体審査が厳格なので要注意

## 必須要件チェックリスト(FANZAアフィリエイト特有)

### 1. 本人・年齢要件
- [ ] 申込者本人が20歳以上であること
- [ ] 本人確認書類の提出(必要な場合。DMMアフィリエイト規約の最新版で要確認)

### 2. DMMアフィリエイト会員登録
- [ ] DMMアカウント作成
- [ ] DMMアフィリエイトへの会員登録・利用規約同意
- [ ] 振込先口座情報の登録(報酬受け取り用)
- [ ] マイナンバー/税務関連情報の登録(必要な場合)

### 3. 掲載媒体(サイト/ブログ/SNS)の準備
アダルト広告掲載可否は媒体ごとに規約が異なるため要確認:
- [ ] 媒体タイプの決定
  - 自己ドメイン+レンタルサーバー(WordPress等)が最も自由度が高く一般的
  - 無料ブログサービス(はてなブログ・note・Ameba等)は**大半がアダルト広告掲載を禁止**しているため非推奨
  - SNS経由での集客を検討する場合、Pinterest/Instagram/TikTok/X等それぞれの規約でアダルトコンテンツ・広告の扱いが異なるため個別に確認が必要(規約違反はアカウント停止リスク)
- [ ] 媒体トップページへの年齢確認(age gate)の設置
- [ ] 特定商取引法に基づく表記ページの設置
- [ ] プライバシーポリシーページの設置
- [ ] DMMアフィリエイトへの媒体登録・審査申請
- [ ] 審査結果の確認(通過/差し戻し)

### 4. コンテンツ・素材の取り扱い
- [ ] FANZAアフィリエイト規約の熟読(禁止表現、誇大広告禁止、著作権画像の利用範囲など)
- [ ] 公式提供のバナー・サンプル画像・アフィリエイトリンクのみ使用する運用ルールの確認(無断転載・二次利用は規約違反になりうる)
- [ ] 紹介記事/レビューの作成方針決定

### 5. リンク・計測
- [ ] アフィリエイトリンク/バナーの発行
- [ ] 媒体への設置
- [ ] クリック率・成果の計測方法の確認(DMMアフィリエイト管理画面)

### 6. 税務
- [ ] 報酬発生後の確定申告要否の確認(金額次第で税理士相談も検討)
