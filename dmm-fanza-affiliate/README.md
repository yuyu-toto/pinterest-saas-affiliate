# dmm-fanza-affiliate

DMMアフィリエイト(FANZA/成人向けジャンル)の副業プロジェクト。

前のパソコンで途中まで作業していたが、環境移行時に記録が消えたため、
今回からこのリポジトリ内で進捗をgit管理する。

> **注意**: このフォルダは `pinterest-saas-affiliate`(Teamwork/Paymo × Pinterest)とは
> 完全に別プロジェクト。商材・媒体・規約が異なるため混在させない。

## ジャンル

- **対象**: FANZA(成人向け動画・電子コミック等)
- 通常のDMM一般ジャンル(DMM英会話・DMM.com物販・ゲーム等)より、年齢要件・掲載媒体審査が厳格なので要注意

## 必須要件チェックリスト(FANZAアフィリエイト特有)

### 1. 本人・年齢要件
- [ ] 申込者本人が20歳以上であること
- [ ] 本人確認書類の提出(必要な場合。DMMアフィリエイト規約の最新版で要確認)

### 2. DMMアフィリエイト会員登録
- [x] DMMアカウント作成
- [x] DMMアフィリエイトへの会員登録・利用規約同意
- [ ] 振込先口座情報の登録(報酬受け取り用) — **要確認**: マイページの口座情報登録状況をチェック
- [ ] マイナンバー/税務関連情報の登録(必要な場合)

### 3. 掲載媒体(サイト/ブログ/SNS)の準備
アダルト広告掲載可否は媒体ごとに規約が異なるため要確認:
- [x] 媒体タイプの決定 → **自己ドメイン+レンタルサーバー(WordPress等)で新規サイトを構築する方針に決定**(Xのみでの申請は不承認)
  - 無料ブログサービス(はてなブログ・note・Ameba等)は**大半がアダルト広告掲載を禁止**しているため非推奨
  - X単体は媒体として不承認になった実績あり(理由非開示)。集客導線としては将来的に併用検討するが、審査に出す「媒体」としては自己ドメインサイトを主軸にする
- [ ] 媒体トップページへの年齢確認(age gate)の設置
- [ ] 特定商取引法に基づく表記ページの設置
- [ ] プライバシーポリシーページの設置
- [ ] 記事コンテンツを複数本用意(空サイトでの審査申請は通過しにくい)
- [ ] DMMアフィリエイトへの媒体登録・審査申請
- [ ] 審査結果の確認(通過/差し戻し)

#### 過去の審査結果(記録)
- サイト名「wagenn2527」で申請 → **不承認**。DMMからの通知メールには具体的な否認理由の記載なし、問い合わせても回答しない方針との明記あり
- 不承認の典型原因(要チェック): コンテンツ不足/年齢確認なし/特商法表記なし/プライバシーポリシーなし/サイト名や運用実態が不審 など。今回どれに該当していたか特定はできないため、新サイトでは全項目を満たした上で申請する

## タスクロードマップ(優先順・更新版)

1. **振込先口座登録の確認** — DMMアフィリエイトのマイページで登録状況をチェック(未登録なら登録)
2. **新サイトの器を用意** — ドメイン取得・アダルト運用可能なレンタルサーバー契約・WordPressセットアップ
3. **必須ページの実装** — 年齢確認(age gate)・特定商取引法に基づく表記・プライバシーポリシー
4. **コンテンツを複数本用意** — 空サイトでの審査申請を避けるため、記事を用意してから申請する
5. **DMMアフィリエイトへサイト追加申請** — マイページの「サイト追加申請」から新サイトを登録
6. **審査通過後、アフィリエイトリンク/バナーを発行・設置**
7. **成果を計測し、税務対応(確定申告)の要否を確認**
