# 記事の書き方スタイルガイド

成果を出しているアフィリエイト/転職系ブログの型を調査し、まとめたもの。
今後の記事執筆時はこれを土台にする。

## 基本構成: PREP法

1. **Point(結論)** — 記事の答え・要点を先に示す
2. **Reason(理由)** — なぜそう言えるのか
3. **Example(具体例・体験談)** — 実例や体験談で説得力を持たせる
4. **Point(再結論)** — もう一度要点をまとめる

見出し(H2)ごとにこの流れを意識すると、読者が離脱しにくい。

## 信頼性(E-E-A-T)を作る書き方

- **メリットだけでなくデメリットも正直に書く**。都合の良い情報だけの記事は読者にもGoogleにも見抜かれる
  → 例: dodaチャレンジ記事で「求人は都市部に厚みがある」と正直に書いたのは正しい方向性
- **体験談・具体的なエピソード**を入れるとオリジナリティと説得力が増す(自分自身の話でなくても、想定される読者像の悩みを具体的に描写するだけでも効果がある)
- 情報源や運営者情報を明記し、記事が「誰が書いたか分かる」状態にする

## キーワード戦略

- 「おすすめ」「ランキング」など大手が独占するビッグキーワードより、**悩み解決系のロングテールキーワード**(検索数100〜500程度)を狙う方が個人ブログでも上位表示しやすい
  → 例: 「転職エージェント おすすめ」より「地方 障害者 転職 オンライン相談」のような具体的な悩みに寄せる
- 記事タイトルは「疑問形」「悩みへの共感」から入ると読まれやすい(今回の「地方在住でも使える?」も好例)

## CTA(行動喚起)の置き方

- 押しつけがましく「今すぐ登録!」と煽らない。読者が納得した上で自然に行動できる流れを作る
- 記事の最後だけでなく、悩みへの答えが出たタイミング(記事中盤)にもさりげなくリンクを置くと機会損失を防げる
- 書き終えたら「自分が読者だったら行動したくなるか」を読み返してチェックする

## 執筆時のチェックリスト

- [ ] タイトルは読者の悩み・疑問に直結しているか
- [ ] 結論を早めに提示しているか(PREP)
- [ ] メリットだけでなくデメリット・注意点も書いているか
- [ ] 体験談や具体例で説得力を持たせているか
- [ ] 事実確認済みの情報のみを書いているか(誇張・断定しすぎない)
- [ ] CTAは自然な流れに置かれているか
