# asp-general-affiliate

一般ジャンルのASPアフィリエイト(A8.net等)の副業プロジェクト。
`dmm-fanza-affiliate`でアダルトジャンル特有の厳しい媒体審査に苦戦したため、
サイト審査のない/緩やかな一般ジャンルで、無料コストで進める方針に切り替えた。

> **注意**: `pinterest-saas-affiliate`(海外SaaS × Pinterest)、`dmm-fanza-affiliate`
> (FANZA)とは別プロジェクト。3つは商材・媒体・規約が異なるため混在させない。

## 方針

- **ASP**: A8.net(会員登録無料・**サイト審査なし**・登録後すぐ開始可能。国内主要ASP調査で16年連続No.1)
  - 他候補: もしもアフィリエイト、afb、バリューコマース、楽天アフィリエイト、Amazonアソシエイト(いずれも会員登録は無料)
- **媒体**: 無料ブログサービス(はてなブログ・FC2ブログ・Seesaaブログ等)を想定。ドメイン代・サーバー代ゼロで開始できる
  - note・Amebaブログはアフィリエイトリンクの扱いに制限があるサービスもあるため、実際に使う前にそのブログサービスの規約でアフィリエイトリンク可否を確認する
- **ジャンル**: **地方転職(Uターン/Iターン転職)** に決定
  - ユーザーが「転職」「旅行」双方に知見があり、地方移住・地域の暮らしの話題も絡められる掛け合わせニッチとして選定
  - 大手転職メディアは20〜30代の都市部向けが中心で、「地方特化」の切り口は比較的手薄
  - A8.netには人材・転職系だけで300件以上のプログラムがあり、多くは「会員登録(報酬目安約1,000円)」「転職相談実施(報酬目安5,000〜15,000円)」など**実際に転職しなくても成果になる**設計のため初心者向き([出典](https://a8pr.jp/2024/01/17/20240117_jobs/), [出典](https://www.a8.net/campus/campus-blog/6435-job-change-affiliate.html))
  - 地方特化・Uターン/Iターン専用プログラムがどれだけあるかはA8.net登録後に実際に検索して確認する。専用プログラムがなくても、リクルートエージェント/doda等の一般転職エージェントは地方求人も扱っているため「地方転職」という切り口で紹介すること自体は可能

## 必須要件チェックリスト

### 1. ASP会員登録
- [ ] A8.net会員登録(無料、サイト審査なし)
- [ ] 振込先口座情報の登録

### 2. ジャンル・商材選定
- [ ] 扱うジャンルを決定(ユーザーの興味・知見・競合状況を踏まえて選ぶ)
- [ ] ASP管理画面で該当ジャンルの広告主(プログラム)を検索し、提携申請
- [ ] 継続報酬型かどうか等、規約を確認

### 3. 媒体準備
- [ ] 無料ブログサービスを選定・開設(はてなブログ/FC2ブログ/Seesaaブログ等)
- [ ] そのブログサービスの規約でアフィリエイトリンク掲載可否を確認
- [ ] プロフィール・自己紹介など最低限の体裁を整備

### 4. コンテンツ作成
- [ ] 記事テーマの洗い出し
- [ ] 記事執筆(最初の数本)
- [ ] アフィリエイトリンクの設置

### 5. 計測・改善
- [ ] クリック率・成果発生の計測(ASP管理画面)
- [ ] 反応を見ながら記事を追加・改善

### 6. 税務
- [ ] 報酬発生後の確定申告要否の確認
